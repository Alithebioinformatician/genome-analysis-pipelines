# Microbial Genomics Analysis Scripts

This repository contains standardized bash pipelines developed for prokaryotic pan-genome analysis. 

## Files Included:
* `prokka_parallel.sh`: Automates structural annotation of raw genomic assemblies.
* `panaroo.sh`: Executes advanced pangenome graph generation and core/accessory genome computation.

These scripts were designed to streamline data processing within a local server environment, abstracting complex command-line parameters to ensure reproducibility for downstream functional annotation.
